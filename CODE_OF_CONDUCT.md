# Code of Conduct

986 VPS Engine welcomes technical discussion, bug reports and contributions from users with different levels of experience.

## Expected behavior

- Keep discussion technical, specific and respectful.
- Critique code and design decisions rather than people.
- Do not publish credentials, private keys, customer data or other sensitive information.
- Respect upstream licenses, authorship and attribution.
- Do not use project spaces to coordinate abuse, unauthorized access or unlawful interception.
- Give maintainers enough reproducible information to evaluate bugs safely.

## Unacceptable behavior

Harassment, threats, discriminatory abuse, deliberate disclosure of private information, spam, impersonation, or knowingly submitting malicious code are not acceptable.

## Enforcement

Maintainers may edit, hide, lock or remove contributions and discussions that violate this policy, and may restrict participation when necessary to protect the project or its users.

Security vulnerabilities should follow `SECURITY.md` rather than being disclosed with exploit details in a public issue.
